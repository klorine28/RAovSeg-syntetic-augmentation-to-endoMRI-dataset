Synthetic MRI samples — exp1b_ddpm_spade
=================================

Generated by src/Generator/generate_samples.py

Settings:
  Conditioning      : spade
  Checkpoint step   : 80000
  Weights           : EMA
  Guidance scale    : 2.0
  DDIM steps        : 100
  Selection seed    : 0
  Samples generated : 50 (20 ovary-containing, 30 other-anatomy)

File naming (NNN = 000..049):
  synth_NNN.png    — synthetic T2FS pelvic slice (the model's output)
  overlay_NNN.png  — synthetic + label overlay (organ colors)
  real_NNN.png     — real MRI slice that the label was extracted from
  label_NNN.png    — label argmax visualisation

Label color key:
  Yellow = uterus
  Red    = left ovary
  Blue   = right ovary
  Green  = endometrioma
  Gray   = body (non-target tissue)
  Dark   = outside body

manifest.csv lists each sample's source subject ID, z-slice index,
and organ presence flags.

Cross-variant comparison:
  Use the SAME --seed across runs (e.g. 1a and 1b) to produce
  matched-anatomy samples — synth_000.png will correspond to the
  same label in both variants. Useful for direct head-to-head
  comparison by a radiologist.
